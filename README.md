# Датасет просмотров видеосервиса

## Описание датасета

Этот репозиторий содержит датасет взаимодействий пользователей с контентом видеосервиса (видео по запросу).

Датасет включает 2 042 796 взаимодействий 351 781 пользователя с 13 334 объектами. В него входят взаимодействия пользователь-объект с их характеристиками (временные метки, длительность и процент просмотра), а также демография пользователей и подробные метаданные объектов.

### Датасет состоит из трёх частей:

1. **interactions.csv** — имплицитные взаимодействия пользователь-объект: процент и длительность просмотра, даты
2. **users.csv** — демография пользователей (пол, возрастная группа, группа дохода, наличие детского профиля)
3. **items.csv** — метаданные объектов (название, оригинальное название, год выпуска, жанры, ключевые слова, описание, страны, студии, актёры, режиссёры, тип контента, возрастной рейтинг)

## Файлы

### interactions.csv

| Колонка | Описание |
|---|---|
| `user_id` | уникальный идентификатор пользователя |
| `item_id` | уникальный идентификатор объекта |
| `last_watch_dt` | дата последнего просмотра |
| `total_dur` | суммарная длительность просмотра, секунды |
| `watched_pct` | процент просмотра объекта |

### users.csv

| Колонка | Описание |
|---|---|
| `user_id` | уникальный идентификатор пользователя |
| `age` | возрастная группа |
| `income` | группа дохода |
| `sex` | пол пользователя |
| `kids_flg` | наличие детского профиля в аккаунте |

### items.csv

| Колонка | Описание |
|---|---|
| `item_id` | уникальный идентификатор объекта |
| `content_type` | фильм / сериал |
| `title` | название |
| `title_orig` | оригинальное название |
| `release_year` | год выпуска |
| `genres` | жанры через запятую |
| `countries` | страны через запятую |
| `for_kids` | предназначен ли объект для детей |
| `age_rating` | возрастной рейтинг |
| `studios` | студии через запятую |
| `directors` | режиссёры через запятую |
| `actors` | актёры через запятую |
| `description` | описание объекта |
| `keywords` | ключевые слова через запятую |

## Задача

Датасет используется для задачи построения рекомендательной системы в обучающих целях: по истории взаимодействий нужно предсказать, с какими объектами пользователь провзаимодействует далее.
